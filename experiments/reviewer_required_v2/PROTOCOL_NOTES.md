# 实验边界与解释口径

本包的主线不是重新选择 q，也不是重做正式 q185 质量实验。q224 只回答“更宽共享基是否具有质量敏感性”，而 q185 仍是冻结主点。

服务阶段比较同一台卡上的 Full、CoreFlow q185 和已完成的 CoMoL native checkpoint。两种硬件需要分别执行，不能从一张卡推断另一张卡的绝对数值。`c4` 采用一个进程内顺序处理请求，用来观察排队负载下的尾延迟和资源变化；它不实现 continuous batching。

隐状态漂移是诊断，不是质量替代指标：它用于说明压缩后差异出现在哪些层、路由和最终 logits，不用于事后改变正式判定。

可选的 group2 独立专家组、完整第二模型质量复验和真实服务框架压测不进入本包的一键路径，以免在用户希望快速完成时意外产生大规模训练和结果混用。
