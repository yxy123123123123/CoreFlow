# Claim boundaries

- q224 is a registered sensitivity point and does not replace q185.
- CoMoL comparisons include the eight independent LoRA training runs in lifecycle accounting; no-training-at-all is not claimed.
- Group2 and group3 use the full six-dataset quality protocol. They are repeatability evidence, not new architecture search.
- The service c4 condition is a single-worker queued-load measurement. It is not continuous batching.
- Cross-hardware claims are restricted to hardware labels that were actually run with the same script and configuration.
- Stored bytes, effective payload, logical parameters, allocated memory, and reserved memory are reported separately.
